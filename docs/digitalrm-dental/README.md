# DigitalRM Dental

Documentação de produto e engenharia da edição voltada a clínicas odontológicas.

## Decisão de produto

Este repositório é uma cópia independente do DeskcommCRM para a vertical **DigitalRM Dental**.
Ele mantém a licença, os avisos de autoria e a infraestrutura de segurança do projeto de origem.
As mudanças desta vertical não devem alterar a instalação já em produção em
`crm.ronaldolabs.com.br`.

## Ordem de leitura

1. [Arquitetura e escopo do MVP](./01-arquitetura-mvp.md)
2. [Setup local seguro](./02-setup-local.md)

## Regra de dados

Até uma etapa futura, aprovada e desenhada especificamente para isso, o produto não armazena
prontuário, anamnese, diagnóstico, radiografia, prescrição ou qualquer anotação clínica. O MVP
opera a camada comercial e administrativa da clínica.
